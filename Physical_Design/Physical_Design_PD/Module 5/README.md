# Module 5 — Final Steps for RTL2GDS Using TritonRoute and OpenSTA

## Overview

This module covers the final physical-design stages after placement and clock-tree synthesis, with emphasis on power distribution, routing, TritonRoute, connectivity, DRC, and post-route outputs.

## Topics Covered

1. Maze routing using Lee's algorithm
2. Design-rule checking (DRC)
3. Power distribution network construction
4. Power straps and connection to standard-cell power
5. Global routing
6. Detailed routing
7. TritonRoute configuration and features
8. Route-guide generation and handling
9. Inter-guide connectivity
10. Intra-layer routing
11. Inter-layer routing
12. Connectivity handling
13. Routing topology
14. Macro and RAM-related physical-design views
15. Post-route files and statistics
16. Final DRC-clean verification

## Practical Figures

All Module 5 figures supplied in `PD_Module_345.zip` are stored in this module's `Images` directory.

## Learning Outcome

This module provides practical exposure to the final RTL-to-GDS implementation stages, from power distribution and route planning through global/detail routing, connectivity verification, DRC, and post-route results.
