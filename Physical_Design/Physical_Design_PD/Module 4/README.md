# Module 4 — Pre-Layout Timing Analysis and Importance of Good Clock Tree

## Overview

This module focuses on timing modelling, pre-layout static timing analysis, timing-library preparation, setup analysis, clock uncertainty, clock-tree synthesis, buffering, crosstalk, shielding, and real-clock setup/hold analysis.

## Topics Covered

1. Timing modelling using delay tables
2. Grid-to-track conversion
3. Layout-to-LEF preparation
4. Track and grid information
5. Timing-library characterization
6. Characterization for cells
7. OpenSTA pre-layout timing analysis
8. SDC/base SDC concepts
9. Clock creation and ideal-clock analysis
10. Setup-time analysis
11. Clock jitter and uncertainty
12. Synthesis optimization for setup violations
13. TritonCTS clock-tree synthesis
14. H-Tree and clock buffering concepts
15. Clock-tree implementation
16. Crosstalk and delta-delay considerations
17. Clock shielding
18. Real-clock setup and hold analysis
19. Power-related characterization such as leakage power
20. Macro and placement-related physical-design views

## Practical Figures

All Module 4 figures supplied in `PD_Module_345.zip` are stored in this module's `Images` directory.

## Learning Outcome

This module develops practical understanding of how timing constraints and clock-tree implementation affect physical design, and how OpenSTA and TritonCTS are used before and during clock implementation.
