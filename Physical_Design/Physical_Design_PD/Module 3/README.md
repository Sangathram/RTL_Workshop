# Module 3 — Design Library Cell Using Magic Layout and ngspice Characterization

## Overview

This module covers CMOS inverter simulation and characterization, CMOS fabrication concepts, standard-cell layout using Magic, Sky130 technology layers, SPICE extraction, and design-rule checking.

## Topics Covered

1. CMOS inverter threshold and voltage-transfer characteristics
2. Static and dynamic behavior of a CMOS inverter
3. ngspice simulation and waveform analysis
4. Creating and understanding a SPICE deck
5. SPICE values and simulation parameters
6. CMOS inverter switching-threshold analysis
7. CMOS fabrication process flow
8. P-substrate formation
9. SiO2 formation
10. Photoresist processing
11. N-well and P-well formation
12. Gate formation
13. Source and drain formation
14. Contact formation
15. Etching
16. Metal formation
17. Basic Sky130 layers and layout concepts
18. Standard-cell layout using Magic
19. Pin configuration and floorplan-related setup
20. SPICE extraction from layout
21. Sky130 model-file usage and characterization
22. Magic options and DRC rules
23. Connectivity and layout verification

## Practical Figures

All Module 3 figures supplied in `PD_Module_345.zip` are stored in this module's `Images` directory.

## Learning Outcome

This module connects transistor-level behavior, CMOS fabrication, layout, extraction, simulation, and physical verification, giving practical exposure to the creation and characterization of a standard-cell library element.
