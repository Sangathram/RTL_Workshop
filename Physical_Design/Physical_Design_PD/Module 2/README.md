# Module 2 — Good Floorplan vs Bad Floorplan and Introduction to Library Cells

## Overview

This module focuses on chip floorplanning, utilization and aspect ratio, placement, physical-design views, standard-cell libraries, and the basic cell-design and characterization flow.

## Topics Covered

1. SKY130_D2_SK1 — Chip Floorplanning Considerations
2. SKY_L1 — Utilization Factor and Aspect Ratio
3. Pre-placed cells and floorplan considerations
4. Decoupling capacitors
5. Power planning
6. Pin placement
7. Floorplan execution and inspection using Magic
8. Cell design and characterization flow
9. General timing characterization parameters
10. Library binding and placement optimization
11. RePlAce and congestion-aware placement
12. Metal layers and standard-cell placement
13. Introduction to Sky130 library cells and physical views
