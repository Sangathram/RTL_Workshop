# Module 3 — Design Library Cell Using Magic Layout and ngspice Characterization

## Overview

This module connects transistor-level simulation, CMOS fabrication concepts, standard-cell layout, SPICE extraction, Sky130 technology layers, and physical verification.

## Topics Covered

1. CMOS inverter threshold and voltage-transfer characteristics
2. Static behaviour of a CMOS inverter
3. Static and dynamic simulation
4. SPICE deck creation and SPICE values
5. ngspice waveform analysis
6. CMOS inverter simulation
7. CMOS fabrication process flow
8. P-substrate formation
9. SiO2 formation
10. Photoresist processing
11. N-well and P-well formation
12. Gate formation
13. Source and drain formation
14. Contact formation
15. Etching
16. Metal formation
17. Sky130 diffusion and polysilicon layers
18. Standard-cell/inverter layout using Magic
19. Pin configuration and floorplan setup
20. SPICE extraction and model usage
21. Connectivity checking
22. DRC-related layout verification
