# Module 5 — Final Steps for RTL2GDS Using TritonRoute and OpenSTA

## Overview

This module covers the final implementation stages: power distribution, routing, TritonRoute, route guides, routing topology, connectivity, DRC, and post-route results.

## Topics Covered

1. Maze routing using Lee's algorithm
2. Design-rule checking (DRC)
3. Power distribution network construction
4. Power straps and connection to standard-cell power
5. Global routing
6. Detailed routing
7. TritonRoute configuration and features
8. Route-guide handling
9. Inter-guide connectivity
10. Intra-layer and inter-layer routing
11. Connectivity handling
12. Routing topology
13. Macro / RAM physical-design views
14. Routing statistics
15. Post-route files and results
16. DRC-clean verification
