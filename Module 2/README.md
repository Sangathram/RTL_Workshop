# Module 2 — Good Floorplan vs Bad Floorplan and Introduction to Library Cells

## Overview

This module focuses on chip floorplanning, utilization and aspect ratio, cell design and characterization, timing-characterization parameters, placement, physical-layout visualization, Sky130 library cells, and metal layers.

## Topics Covered

1. **SKY130_D2_SK1 — Chip Floorplanning Considerations**
2. **SKY_L1 — Utilization Factor and Aspect Ratio**
3. Cell Design and Characterization Flows
4. General Timing Characterization Parameters
5. Floorplan visualization using Magic
6. Standard-cell placement
7. Metal layers and physical-design views
8. Sky130 library cells
9. Synthesized netlist and its relation to placement
10. Floorplan and placement inspection
